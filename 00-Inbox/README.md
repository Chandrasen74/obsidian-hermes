# 00-Inbox

This is your default capture zone for:
- Fleeting thoughts and ideas
- Meeting notes and action items
- Quick captures from phone or web
- Anything that needs processing later

Process items from here to the appropriate PARA folder within 24-48 hours.

## Processing Guidelines
1. **Review daily** - Go through everything in this folder
2. **Categorize** - Move items to Projects, Areas, or Resources based on their nature
3. **Archive or delete** - Remove anything that's no longer needed
4. **Reference** - Keep only what requires immediate attention in this folder
