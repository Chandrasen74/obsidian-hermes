# 00-Inbox

This is your inbox for unprocessed notes and incoming files.

**Purpose:**
- Temporary holding area for new notes, files, and items needing processing
- Process items regularly (daily/weekly) and move them to appropriate PARA folders
- **Do not store permanent files here** - this is a processing queue only

**Processing Guidelines:**
1. Review new items promptly
2. Determine if item is actionable, reference, or trash
3. Move to appropriate PARA folder:
   - **01-Projects/** - For active projects with specific outcomes
   - **02-Areas/** - For ongoing responsibilities/areas of focus
   - **03-Resources/** - For reference materials and information
   - **04-Archives/** - For inactive items from the above categories
4. Delete trash items

**PARA Method Reference:**
- Projects: Short-term efforts with a clear goal and deadline
- Areas: Ongoing responsibilities requiring maintenance
- Resources: Topics of interest or reference materials
- Archives: Inactive items from the other three categories

**Note:** Keep this folder as empty as possible. Process items to zero regularly.
