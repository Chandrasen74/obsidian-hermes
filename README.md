# Obsidian Second Brain & Worksheet Engine

This repository contains my personal Obsidian vault, configured as a "second brain" for organizing knowledge, along with an autonomous worksheet generation engine for Delhi Public School, Gurugram.

## Repository Structure
- `MAQC-7/`: Contains materials, evidence, and planning for the MAQC-7 project.
- `Worksheet/`: Contains the `Worksheet X-A` autonomous generator template and usage guide.
- `.obsidian/`: Obsidian configuration files.

## Getting Started
To open this repository as an Obsidian vault:
1. Clone this repository.
2. Open Obsidian.
3. Select "Open folder as vault" and choose the root directory of this repository.

## Commands
- To start your second brain workflow with Hermes, use the `omniroute` command.
