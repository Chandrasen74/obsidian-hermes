CH 1 • REAL NUMBERS
Real Numbers • 6M fix
a = bq + r , 0 ≤ r < b   •   HCF × LCM = a × b (2 nos only)
  • Euclid Algorithm: HCF(a,b)=HCF(b,r) → repeat till r=0. Ex: 404,96 → HCF 4
  • FTA: 140 = 2²·5·7. HCF=min power, LCM=max power
  • Terminating? Denom = 2ⁿ·5ᵐ → Yes. Ex: 17/80=2⁴·5 → Terminating ✓ ; 29/343=7³ → Non-term
Irrational Proof (√2): Assume √2=p/q → p²=2q² → p=2r → q²=2r² → q also ×2 → contradiction → irrational ■ Same for √3, 3+2√5 (isolate √5)

Polynomials • Zeroes

CH 3 • PAIR OF LINEAR EQS
Pair of Linear Eqs • a₁x+b₁y+c₁=0
a₁/a₂ ≠ b₁/b₂
Intersecting ☓ → Unique Consist.
= b₁/b₂ = c₁/c₂
Coincident ≡ → Infinite
= b₁/b₂ ≠ c₁/c₂
Parallel ∥ → No sol Inconsist.
x/(b₁c₂-b₂c₁)= y/(c₁a₂-c₂a₁)=1/(a₁b₂-a₂b₁) Cross
Methods: Substitution (coeff 1) • Elimination (make equal) • Cross. Ex: infinite for 2/(k+1)=3/(2k-1) → k=5

CH 5 • AP
Arithmetic Progression • a, a+d, ...
aₙ = a + (n-1)d   •   Sₙ = n/2[2a+(n-1)d] = n/2(a+l)
  • a,b,c in AP → 2b = a+c
  • 3 terms: a-d, a, a+d (sum 3a) • 4 terms: a-3d,a-d,a+d,a+3d (sum 4a)
  • Which term is -81? → aₙ=-81 → find n. If n not integer → not a term
Ex: 3,1,-1... d=-2 → a₁₀=3+9(-2)=-15 • S₂₂ for 8,3,-2 = -979
CH 6 • TRIANGLES
Triangles • 5M proof
BPT: DE∥BC → AD/DB = AE/EC   Converse true ★ Prove!
  • Criteria: AA (2 angles), SSS (3 sides prop.), SAS (1 angle + sides prop.)
  • ar1/ar2 = (side1/side2)² — similar triangles
  • Pythagoras: Hyp² = Perp² + Base² (Right Δ) ★ Prove!
