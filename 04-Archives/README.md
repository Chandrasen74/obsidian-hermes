# 04-Archives

**Definition:** Inactive items from the other three categories.

**When to archive:**
- Projects completed or cancelled
- Areas no longer relevant
- Resources outdated or superseded

**Organization:**
- Keep same folder structure as source
- Add date or reason if helpful: "ProjectName_Completed_2026-09"
- Review annually for potential restoration
- Searchable but out of active workflow
