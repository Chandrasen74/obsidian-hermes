Practical 1: Basic HTML Page with Headings
Aim: To create a simple web page using the basic HTML structure and heading tags.
HTML Code:
<!DOCTYPE html>
<html>
<head>
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to My Web Page</h1>
    <h2>Computer Applications</h2>
    <p>This is my ﬁrst HTML practical.</p>
</body>
</html>
Expected Output: A browser page showing the heading “Welcome to My Web Page”, a 
smaller heading “Computer Applications”, and a paragraph.

Practical 2: Text Formatting and Line Breaks
Aim: To display bold, italic, underlined, and line-broken text.
HTML Code:
<!DOCTYPE html>
<html>
<head>
    <title>Text Formatting</title>
</head>
<body>
    <h1>Text Formatting in HTML</h1>
    <p><b>This text is bold.</b></p>
    <p><i>This text is italic.</i></p>
    <p><u>This text is underlined.</u></p>
    <p>HTML is used to create web pages.<br>
       It uses tags to structure content.</p>
    <p>Water formula: H<sub>2</sub>O</p>
    <p>Square: x<sup>2</sup></p>
</body>
</html>
Expected Output: The browser displays bold, italic, underlined text, a line break, H₂O, and x².

Practical 4: Hyperlink to a Website
Aim: To create a clickable hyperlink using the anchor tag.
HTML Code:
<!DOCTYPE html>
<html>
<head>
    <title>Useful Website</title>
</head>
<body>
    <h1>Learn HTML</h1>
    <p>Visit the W3Schools website to learn more:</p>
    <a href="https://www.w3schools.com/html/">Learn HTML</a>
</body>
</html>
Expected Output: A clickable link labelled “Learn HTML” appears. Clicking it opens the linked 
website in the browser.

Practical 5: Insert an Image
Aim: To display an image on a web page using the img tag.
HTML Code:
<!DOCTYPE html>
<html>
<head>
    <title>My School</title>
</head>
<body>
    <h1>My School</h1>
    <p>Here is a picture for my web page.</p>
    <img src="school.jpg" alt="School picture" width="300">
</body>
</html>
Expected Output: The browser displays the image school.jpg at a width of 300 pixels, if the 
image file is in the same folder.
Note: Replace school.jpg with the actual image filename. The alt text is shown if the image 
cannot load.

Practical 10: Simple Feedback Form
Aim: To create a basic HTML form with text input, radio buttons, a drop-down list, and a 
submit button.
HTML Code:
<!DOCTYPE html>
<html>
<head>
    <title>Feedback Form</title>
</head>
<body>
    <h1>Website Feedback</h1>
    <form>
        <label for="name">Name:</label>
        <input type="text" id="name" name="name"><br><br>
        <p>How was the website?</p>
        <input type="radio" id="good" name="rating" value="Good">
        <label for="good">Good</label>
        <input type="radio" id="average" name="rating" value="Average">
        <label for="average">Average</label><br><br>
        <label for="topic">Favourite topic:</label>
        <select id="topic" name="topic">
            <option>HTML</option>
            <option>Lists</option>
            <option>Tables</option>
        </select><br><br>
        <input type="submit" value="Submit">
    </form>
</body>
</html>
Expected Output: A simple feedback form appears. The submit button demonstrates the 
form control; it will not store or send responses without a server or form-processing service.
Note: Use only fictional/sample details in practice files; do not enter sensitive personal 
information.
