# 01-Projects

**Definition:** Active endeavors with a specific goal and deadline.

**Characteristics:**
- Have a clear outcome (done/not done)
- Have a deadline or target completion date
- Require multiple steps/actions to complete
- Examples: "Launch website", "Plan vacation", "Finish research paper"

**Organization:**
- Each project gets its own folder or note
- Use clear, action-oriented names (verb + object)
- Link to related notes in Areas/Resources
- When completed, move to 04-Archives
